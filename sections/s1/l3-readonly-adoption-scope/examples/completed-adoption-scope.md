# AI運用導入スコープ

## 目的

架空の検証環境「training-observability」で、AIをメトリクス・マスキング済みログの調査、情報整理、報告案作成に限定して利用する。既存の障害対応、変更承認、復旧判断を置き換えない。

## 対象環境

| 項目 | 記入内容 |
| --- | --- |
| 環境 | 架空の非本番検証環境 training-observability |
| 対象サービス | 提供済みのメトリクス要約、マスキング済みアプリケーションログ |
| 対象外 | 実AWS環境への接続、本番データ、IAM、リソース変更、リリース、復旧実行 |

## 事実

- 監視通知では、13:05からWeb APIのp95レイテンシ上昇が記録されている。
- 提供済みログには13:07からタイムアウト件数が増えた記録がある。
- 調査用の入力は架空データで、AWS認証情報を含まない。
- 一部の未確認ログは、マスキング済みかどうか判断できていない。

## 仮説

- レイテンシ上昇とタイムアウト増加には同じ原因がある可能性があるが、相関だけでは原因を確定できない。
- データベース負荷が影響した可能性はあるが、データベースの観測情報がないため未検証である。
- 再起動で回復する可能性はあるが、利用者影響、冗長化状態、変更承認が未確認である。

## ReadOnly境界

| 観点 | 許可範囲 | 禁止範囲 |
| --- | --- | --- |
| 情報源 | 演習で提供されたメトリクス要約とマスキング済みログ | 未確認ログ、本番データ、認証情報、個人情報 |
| API操作 | この演習ではAPIを呼ばず、ローカルファイルだけを読む | AWSへの接続、作成、更新、削除、権限変更、コマンド実行 |
| 出力 | 情報源と時刻を付けた事実、仮説、不明点、報告案 | 原因の断定、機密情報の転記、承認済み変更指示に見える表現 |

## 作業分類

判断区分は「AIが実行してよい（`ALLOW`）」「AIは実行しない（`PROHIBIT`）」「人間の確認が必要（`HUMAN_REVIEW`）」を表します。

| 作業 | 判断区分 | 根拠 | AIが行える範囲 |
| --- | --- | --- | --- |
| 提供済みメトリクスを時系列に整理する | ALLOW | 承認済みの架空データを読むだけ | 時刻、値、情報源を示す |
| マスキング済みログからエラー件数を集計する | ALLOW | 機密情報を除いたReadOnly調査 | 件数と対象期間を示す |
| 事実・仮説・不明点を分けた報告案を作る | ALLOW | 最終判断ではなく報告補助 | 断定せず根拠を添える |
| インスタンスを再起動する | PROHIBIT | リソース状態を変更する | 実行しない |
| IAMポリシーを追加または変更する | PROHIBIT | 権限境界を変更する | 実行しない |
| リソースやログを削除する | PROHIBIT | 不可逆な影響と証跡喪失がある | 実行しない |
| 未確認ログをAIへ入力する | PROHIBIT | 機密情報が含まれる可能性がある | 読み取らず停止する |
| 復旧方法を選択する | HUMAN_REVIEW | 利用者影響と変更承認が必要 | 選択肢、不明点、根拠を伝える |
| 追加の参照権限を要求する | HUMAN_REVIEW | 最小権限と監査範囲の審査が必要 | 必要範囲と期間を説明する |
| マスキング状態が不明なデータを扱う | HUMAN_REVIEW | データ分類と取扱承認が必要 | 入力せず確認を依頼する |
| `actor/identity`、`timestamp`、`source`、`session/correlation ID` が欠けた調査結果を扱う | HUMAN_REVIEW | 実行者、時刻、情報源、実行との相関を追跡できず監査不能 | 調査を中断し、欠落項目と影響範囲を伝えて確認を依頼する |

## AIが作業を中断して人間に確認する条件

| 確認が必要になる条件 | AIの動作 | 確認を依頼するときに伝える情報 |
| --- | --- | --- |
| 作成、更新、削除、再起動、リリース、復旧実行が必要 | `NEED_HUMAN_DECISION` として停止 | 観測事実、提案、想定影響、不明点、選択肢 |
| IAMやセキュリティ設定の変更が必要 | `NEED_HUMAN_DECISION` として停止 | 不足している参照範囲、必要期間、代替調査 |
| 本番環境または利用者影響の可能性がある | `NEED_HUMAN_DECISION` として停止 | 対象環境、影響範囲、根拠、確認できていない事項 |
| 機密情報や個人情報の混入、マスキング不明を検知 | 入力と出力を中止 | データ分類、検知箇所、保持・送信の有無、確認事項 |
| 根拠が不足し原因を断定できない | 調査結果を仮説として保留 | 確認済み事実、仮説、反証に必要な情報 |
| `actor/identity`、`timestamp`、`source`、`session/correlation ID` のいずれかが欠ける | `NEED_HUMAN_DECISION` として停止 | 欠落項目、取得済み証跡、調査範囲、正式記録へ採用していないこと |

## 承認

| 役割 | 確認内容 | 状態 |
| --- | --- | --- |
| 演習上の運用責任者 | 対象・対象外とAIが作業を中断する条件 | 承認 |
| 演習上のセキュリティ担当 | ReadOnly境界、監査、情報境界 | 承認 |
